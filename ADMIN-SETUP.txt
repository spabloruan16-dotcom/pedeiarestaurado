PEDEIA - PAINEL ADMINISTRATIVO

1. Este pacote nao inclui .env nem node_modules por seguranca e tamanho.
2. Configure as variaveis no ambiente onde o servidor roda:
   DATABASE_URL = connection string PostgreSQL do Supabase (server-side, nunca no navegador)
   SUPABASE_URL = URL do projeto Supabase
   SUPABASE_ANON_KEY = chave publishable/anon do projeto
   PORT = opcional (padrao 4173)
3. Instale dependencias na pasta PedeIA com npm install e inicie com npm start.
4. A tabela public.admin_roles deve existir e conter o UUID do usuario admin em user_id, com role='admin'.
5. Login admin e comerciante usam Supabase Auth. O servidor confere admin_roles em cada rota administrativa.
6. Ativacao no painel libera por 30 dias; Suspender e Pendente bloqueiam acesso. Confirme as rotas e politicas de assinatura antes de producao.

IMPORTANTE: Nunca exponha DATABASE_URL, senha do banco ou service_role key em app.js, HTML, repositorio publico ou navegador.
